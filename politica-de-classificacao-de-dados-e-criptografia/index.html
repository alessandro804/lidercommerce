Política de Classificação de Dados e Criptografia

Como os dados são classificados por sensibilidade e como cada classe é protegida, em trânsito e em repouso.

Lider Commerce LTDA · CNPJ 46.480.030/0001-43 · Última atualização em 21 de junho de 2026

Objetivo

Definir como os dados são classificados e protegidos de acordo com sua sensibilidade.

Classificação dos dados

Os dados que tratamos são classificados como:

  • Confidencial: dados pessoais de clientes e de seus consumidores (por exemplo, nomes, dados de contato, informações de pedidos).
  • Interno: dados operacionais e de negócio não destinados à divulgação pública.
  • Público: informações aprovadas para divulgação pública.

Criptografia em trânsito

Todos os dados transmitidos entre usuários, nossos sistemas e APIs de terceiros são criptografados via TLS/HTTPS.

Criptografia em repouso

Os dados confidenciais armazenados em nosso banco de dados e armazenamento de arquivos são criptografados em repouso pelos nossos provedores de nuvem. Credenciais e segredos de API são guardados como variáveis de ambiente protegidas.

Tratamento de dados confidenciais

Os dados confidenciais são acessados apenas por pessoas autorizadas, com base no privilégio mínimo, e nunca são armazenados em locais não seguros nem transmitidos por canais não criptografados.
